## Исходная точка Z01

В репозитории есть проектная документация. Исходников прототипа для переноса UI в текущей версии нет. Новая веб-оболочка опирается на экраны из технического дизайна.

## Локальный запуск

Требуется Node.js 24. Из корня проекта запустите `npm run dev:api`. Проверка состояния доступна по адресу `http://127.0.0.1:3000/api/health`.
